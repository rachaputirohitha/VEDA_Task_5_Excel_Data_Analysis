# VEDA Task 5 – Excel Data Analysis

##  Project Overview

This project was completed as part of VEDA Task 5 – Excel Data Analysis. The objective of this task is to analyze the Sample Superstore dataset using Microsoft Excel and identify important business insights related to sales, profit, quantity, discount, and different business categories.

##  Objective

- Analyze sales and profit performance.
- Calculate important business KPIs.
- Perform category-wise formula analysis.
- Analyze data using PivotTables.
- Identify key business findings from the analysis.

##  Dataset

The project uses the **Sample Superstore Dataset**, containing information related to:

- Ship Mode
- Segment
- Country
- City
- State
- Postal Code
- Region
- Category
- Sub-Category
- Sales
- Quantity
- Discount
- Profit

##  Tools Used

- Microsoft Excel
- Excel Formulas
- PivotTables
- Data Analysis

##  Analysis Performed

### Formula Analysis

The following Excel functions were used:

- **SUMIF** – Category-wise Total Sales
- **AVERAGEIF** – Category-wise Average Profit
- **COUNTIF** – Category-wise Number of Records
- **COUNTIFS** – Category-wise Records with Discount greater than 0

### PivotTable Analysis

Four PivotTables were created:

1. Sales & Profit by Category
2. Sales & Profit by Region
3. Sales & Profit by Segment
4. Sales & Profit by Ship Mode

##  Key Performance Indicators (KPIs)

| KPI | Value |
|---|---:|
| Total Sales | 2,297,200.86 |
| Total Profit | 286,397.02 |
| Total Quantity | 37,873 |
| Average Discount | 15.62% |
| Profit Margin | 12.47% |

##  Key Findings

- Technology generated the highest total sales among the three product categories.
- The West region recorded the highest sales and profit among the four regions.
- The Consumer segment contributed the highest sales and profit compared with Corporate and Home Office segments.
- Standard Class was the most commonly used shipping mode and generated the highest sales.
- Overall, the dataset generated strong sales with a positive profit margin.

The analysis provides a clear overview of sales and profitability across different categories, regions, customer segments, and shipping modes. Excel formulas and PivotTables were used to summarize the data and identify meaningful business insights.
